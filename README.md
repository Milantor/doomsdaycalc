### Че это за проект вообще?

Кратко: калькулятор для сбережений с дедлайном и напоминалками  
Длинно: калькулятор для сбережений с дедлайном. В котором куча приколов и ненужных функций. Который использует БД и собирает персональные данные. Который агрессивно мотивирует.

лучший проект в моей жизни, бесспорно. /s

### ✨фичи✨

- ставить цели с дедлайном и до трёх тиров (`min`/`ok`/`max`) — типа "на квартиру наскрести, а если попрёт, то и на еду чтоб хватило"
- класть и снимать деньги. каждое движение — одна подписанная строчка в БД, снятие это отрицательное пополнение. сумма = буквально `SUM()`. если можно просто — делаю просто
- `status` — где ты относительно своего графика: сколько отстаёшь и сколько в день надо, чтобы догнать
- днями и месяцами рулит таймзона юзера, а не сервера, так что "сегодня" и "конец месяца" у всех свои. ну, так планировалось...
- 4 языка: `ru`/`en`/`sr` + `rofl`. Последний я придумал сам слушая пацанский рэпчик, и он единственный, который я написал руками а не заставил этим заниматься ллм
- каждое движение заканчивается фразой, подобранной по размеру: закинул 15к — получил комплимент, снял всю котлету — получил кибербуллинг
- `privacy` — на честном слове объясняет, какие данные хранит и зачем
- `data remove all` — вырезает юзера из базы. полностью.
- админские `send` и `broadcast` — чтобы я мог угарать над юзерами

### Build & Run & Zero fun

Понадобится:

- **Go 1.26** — язык такой. Прикольный на самом деле. Все просто берет и работает. Задумался о том стоило ли учить всю жизнь CS
- **PostgreSQL** — БД. Постгрес крутой, на этом все.

Шаги:

```bash
git clone https://github.com/milantor/doomsdaycalc.git
cd doomsdaycalc
cp .env.example .env
# открыть .env и заполнить хотя бы BOT_TOKEN и DATABASE_URL
go run ./cmd/bot
```

Что за переменные(для кого я комментарии писал?):

| Переменная | Обязательна | Что это |
| --- | --- | --- |
| `BOT_TOKEN` | да | токен от [@BotFather](https://t.me/BotFather) |
| `DATABASE_URL` | да | строка подключения, вида `postgres://user:pass@host:5432/db` |
| `ADMIN_IDS` | нет | id админов через запятую, открывает `send`/`broadcast` |
| `LOG_LEVEL` | нет | по умолчанию `info` |
| `DEBUG` | бесполезна | я забыл как хотел реализовать |

Миграции накатываются сами при старте, руками ничего применять не надо — таблицы тоже создадутся сами. Юзера создай только)

Хочешь отдельный бинарник:

```bash
go build -o doomsdaycalc ./cmd/bot
```

### Команды

Слэш только у `/start` — Telegram присылает его в таком виде, когда долбишь кнопку. мне не нравится. Остальное бот понимает по обычному тексту:

`add`, `withdraw`, `status`, `privacy`, `data remove all`, `lang <код>`, `help`

- `lang ru/en/sr/rofl` — переключить язык. `ru`/`en`/`sr` ещё подхватываются из Telegram сами, `rofl` — только руками, он слишком крутой.
- `send <сценарий> <id|all>` и `broadcast <текст>` — только для админов из `ADMIN_IDS`. Остальным бот просто не отвечает, потому что прав нет))
